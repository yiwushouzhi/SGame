# 灾墟树屋 · 垂直切片原型

《地球上最后的孩子：灾墟树屋》2D 俯视角 ARPG 原型（Godot 4.4+）。
目标：跑通 **战斗 → 拾取 → 合成 → Boss 战 → 回城** 闭环。

## 运行方式

1. 用 **Godot 4.4 或更高版本** 导入本目录（选择 `project.godot`）。
2. 按 `F5` 运行，主场景为 `scenes/main_menu/MainMenu.tscn`。
3. 命令行：

```bash
godot --path /workspace
```

> 原型全部美术由 `_draw()` 程序化绘制，无需导入任何图片资源；中文字体使用 `assets/fonts/SmileySans.otf`。

## 操作键位

| 按键 | 功能 |
| --- | --- |
| WASD / 方向键 | 移动（4.2 码/秒，黄昏起 -0.4） |
| 鼠标左键 | 近战挥击（钉棒球棍，0.75 次/秒） |
| Space | 翻滚（无敌 0.4 秒，距离 3 码，CD 4 秒） |
| Q | 燃烧瓶（24~36 伤害 + 8 秒灼烧，CD 7 秒） |
| F | 捕兽夹（8 伤害 + 定身 3 秒，Boss 1.2 秒，CD 9 秒） |
| 1 / 2 | 快速使用生命 / 理智药水 |
| E | 与 NPC、宝箱、传送门交互 |
| B | 背包 / 角色面板（4×8 格 + 7 装备位） |
| M | 昆特的拾荒魔方（5 条基础配方） |
| T | 战斗中返回树屋 |
| ESC | 暂停菜单（继续 / 返回树屋 / 设置 / 返回主菜单） |

> 原作键位表中 `W` 同时用于前进与捕兽夹，原型将捕兽夹改到 `F`，避免移动冲突。

## 已实现内容

- **杰克**：Lv1~10、生命/理智/经验、暴击（血量 >80% 额外 +10%）、闪避、护甲、翻滚无敌、理智归零失控 8 秒（自动攻击附近目标，每秒恢复 5 理智）。
- **昼夜**：120 秒周期，白天 0~75s / 黄昏预警 75~85s / 黑夜 85~120s。入夜僵尸生命 +30%、伤害 +25%；飞戾怪攻频 +30%；黄昏起怪物移速 +20%，玩家移速 -0.4。黑夜理智每秒 -1（用于验证失控机制，常量 `NIGHT_SANITY_DRAIN` 可关闭）。
- **怪物**：普通僵尸、飞戾怪（远程酸液，保持 4.5~7 码）、小藤蔓、藤蔓母怪 Boss（藤蔓缠绕 / 刺藤喷射 / 召唤 4 只小藤蔓，10 码内激活）。
- **掉落**：普通 / 精英 / Boss 三档品质概率，装备词缀随机生成，靠近自动拾取。
- **装备**：白 / 蓝 / 黄三品质，7 个部位，装备后实时更新伤害、护甲、生命、理智、暴击、移速。
- **魔方**：3 白装 → 蓝装；2 生命药 + 1 理智药 → 混合药水；3 虚空碎片 → 纯净碎片；3 废料 → 捕兽夹 ×2；玻璃瓶 + 破布 + 废料 → 燃烧瓶 ×2。原型成功率 100%。
- **地图**：树屋主城（昆特 / 补给箱 / 看板 / 传送门）+ 城郊居民区（3200×2000，含北侧裂隙 Boss 区、宝箱、返回传送门）。
- **HUD**：左上生命 / 理智 / 经验条与状态图标，右上圆形小地图与任务，底部技能栏 CD，Boss 血条，黄昏 / 黑夜边缘泛紫，死亡遮罩。

## 原型边界

不做联机、不做赛季、不做 4 职业、不做全部四幕、不做复杂动画。
范围仅：杰克、城郊居民区、僵尸 / 飞戾怪 / 藤蔓母怪、拾荒魔方基础配方、昼夜黄昏。

## 数值调整

所有原型数值集中在 `data/*.json`：

- `item_data.json`：物品、装备基础属性、品质倍率、词缀池。
- `recipe_data.json`：5 条魔方配方（输入选择器支持 `id` / `type+rarity`）。
- `enemy_data.json`：三种怪物与 Boss 技能参数。

修改 JSON 后直接重启游戏即可生效，无需改代码。
